# 3D Experience Strategy (R3F)

## 1. 3D Səhnələr
- **Hero (Neural Core):**
  - **Nə:** Mərkəzdə fırlanan, deformasiya olunan Icosahedron (Shader Material).
  - **Məqsəd:** Sistemin "canlı" və "ağıllı" olduğunu göstərmək.
  - **Yer:** Dashboard Hero bölməsi və Login ekranı.
- **Aksentlər:**
  - Arxa planda üzən kiçik hissəciklər (Particles/Stars) - dərinlik hissi üçün.

## 2. Kamera və İnteraksiya
- **Parallax:** Mouse hərəkəti ilə kamera yüngülcə əks tərəfə dönür (`useFrame` + mouse pos).
- **Scroll:** Səhifə aşağı endikcə "Core" obyektinin forması və ya rəngi dəyişir (Scroll-driven animation).

## 3. Performans və Fallback
- **Asset Büdcəsi:** Xarici model (.glb) YOXDUR. Procedural geometry (Mesh) istifadə olunur. Texture max 512x512.
- **Adaptive Quality:** - **Tier 1 (High):** Post-processing (Bloom, Noise) AKTİV. High poly count.
  - **Tier 2 (Low):** Post-processing SÖNDÜRÜLÜR. Low poly count. `drei/PerformanceMonitor` ilə idarə olunur.
- **Fallback:** Əgər WebGL dəstəklənmirsə və ya xəta baş verərsə -> Statik `img` (blurred gradient) göstərilir.

## 4. Acceptance Criteria
- [ ] 3D səhnə əsas UI yüklənməsini bloklamır (lazy load).
- [ ] FPS Counter > 50 (orta seqment cihazda).
- [ ] Canvas ölçüləri resize zamanı düzgün yenilənir.
